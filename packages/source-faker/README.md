# @gridmix/source-faker

> [Faker.js](https://github.com/marak/Faker.js/) source for Gridmix

## Install

- `npm install @gridmix/source-faker`
- `yarn add @gridmix/source-faker`
- `pnpm install @gridmix/source-faker`

## Usage

```js
export default {
  plugins: [
    {
      use: '@gridmix/source-faker',
      options: {
        numNodes: 100
      }
    }
  ]
}
```
