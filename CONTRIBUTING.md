# Contributing

Thanks for stopping by and for caring enough to read this. Gridmix is a small, independent project, labour of love, curiosity, and craftsmanship, so if that resonates, here's what you need to know.

## In a nutshell

- Be decent to people and follow [the code of conduct](./CODE_OF_CONDUCT.md).
- Check out [the README](./README.md) and the dev docs linked there.
- Open an issue before doing any work. Follow the existing template.
- PRs should be small and explained well.
- The project moves at a human pace so be patient and expect no rush.

## AI policy

- AI tools are fine for assistance — ideating on architecture, generating test data, suggesting fixes.
- Don't submit code you don't understand.
- If a large chunk was AI-generated, mention it in the PR description.
- Human judgment and real-world experience are important. If you're using AI to bypass those, this isn't the right project for you.

## That's it

Thanks for being here. It means a lot.
